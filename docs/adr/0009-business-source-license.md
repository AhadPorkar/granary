# 9. Business Source License 1.1

Date: 2026-10-08 · Status: accepted

## Context

Granary is sold commercially and also published in full so that buyers can audit and extend
it, and so that developers, students and open-source projects can use it for free.

## Decision

License the code under the Business Source License 1.1 with an Additional Use Grant covering
evaluation, non-commercial and open-source use, a Change Date four years after each release and
the Mozilla Public License 2.0 as the Change License (MPL 2.0 satisfies the BUSL covenant of
GPL compatibility).

## Consequences

* The repository is public, but it is not Open Source in the OSI sense until the Change Date.
* Switching to a permissive licence later is a one-line change to `LICENSE` and the README.
